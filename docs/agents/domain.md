# Dominio

- **Glosario:** [`GLOSSARY.md`](../../GLOSSARY.md), en la raíz. Da el par español·inglés de cada término: en español lo que lee la dirección, en inglés el código.
- **Decisiones:** `docs/adr/`, un ADR por decisión cerrada (`NNNN-slug.md`). La carpeta se crea con el primer ADR.
- **El contrato con la dirección:** `contract/` y [cli.md](cli.md).

Este repo, `AS-prog/asprog-design-system`, tiene un solo contexto. Antes de planificar, lee el glosario y los ADR que toquen el tema; si una decisión nueva contradice uno, se dice.
