En una frase

El lector pide la humedad a cada sensor, descarta los valores fuera de rango y guarda el resto en readings. No decide cuándo regar: eso es de la programación del riego.

Cómo funciona

Cada diez minutos (READ_INTERVAL = 600) el lector recorre las parcelas de config/plots.yaml.

Cómo se opera

Una lectura a mano, en local

uv run riego read --plot norte --dry-run
SíntomaQué pasaQué hacer
Muchas filas en readings_rejectedEl sensor está fuera de rangoRevisar el sensor de la parcela
